# Что поменялось в коде

Игровая логика сохранена из предыдущего проекта, основанного на примерах преподавателя. Подводный набор используется только как графика: JavaScript-код демонстрационной игры не импортирован.

| Файл | За что отвечает |
|---|---|
| SurvivalPlayerController | Движение, толчок вверх с опоры, параметры Animator Speed / Grounded и поворот спрайта. Кнопка KICK вызывает прежний прыжок. |
| SurvivalCollectibles | Триггер предмета с тегом Coin увеличивает счётчик. В новой теме предмет выглядит как жемчужина; тег оставлен для совместимости с примером. |
| Health | Урон, лечение, мигание и временная неуязвимость; смерть перезапускает сцену. |
| Spawner, Hazard, Rock, BombHazard, Heart | Прежний спавн и реакции на игрока. Rock выглядит как малая мина, Bomb — большая мина, Heart — лечебный пузырёк. |
| Shooter, Bullet, Bomb | Прежние Instantiate, cooldown, движение снаряда и отложенный эффект. Снаряд теперь выглядит как пузырёк; урон снарядом не добавлялся. |
| SurvivalTimer | Через 60 секунд выставляет Open у Animator спасательной арки. |
| HUDView | Читает здоровье, счёт и время. Надписи COINS / SURVIVE / GATE OPEN заменены на PEARLS / DIVE / RESCUE READY. |
| SafeArea | Код SafeArea из лекции 8–9: переводит Screen.safeArea в нормализованные anchors. |
| UIFlow | Загрузка сцен и показ панелей по примеру UI, пауза через Time.timeScale по лекции. |
| MobileControls | Связывает нажатие и отпускание экранных кнопок с прежним движением, прыжком и стрельбой. |

Анимации — готовые кадры из Underwater Diving Pack. В Unity листы нарезаны на спрайты, затем кадры назначены в Idle / Walk / Jump. Старые параметры и переходы Animator сохранены. Графика не была нарисована заново.
