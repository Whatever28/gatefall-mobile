# Pearlbound: asset sources

All active underwater graphics are existing free assets. No generated sprites are used.

| Asset | Author / pack | License / source |
|---|---|---|
| Diver Idle, swimming and kick animation; fish, mines, bubbles, explosions, background, ruins and seabed tiles | Luis Zuno (ansimuz), Underwater Diving Pack | CC0 / public domain. https://opengameart.org/content/underwater-diving-pack |
| Pearl pickup | MallardTV, 16x16 Pearl | CC0. https://opengameart.org/content/16x16-pearl |
| Shoot, hurt and pickup sounds | Kenney, Digital Audio | CC0. https://kenney.nl/assets/digital-audio |
| UI font | Liberation Sans | SIL Open Font License; original license in Assets/TextMesh Pro/Fonts |

Original license notices are retained in Assets/Art/Underwater and Assets/Audio/Kenney. Spritesheets are sliced into frames using Unity's Sprite Editor/import data. The pack's JavaScript game code and demo music are not imported. Unity C# gameplay remains based on the instructor's examples from the earlier assignments.
